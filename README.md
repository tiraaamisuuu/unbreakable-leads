# Unbreakable Leads

A Fabric mod for Minecraft Java Edition 26.2 that prevents leads from automatically breaking in single-player worlds and on dedicated servers.

## Target

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 or newer
- Java 25
- Fabric API where useful
- Client and dedicated-server compatible

## Goals

- Keep player-held and fence-attached leads from snapping because of distance or speed.
- Remain safe across chunk unloads, reconnects, and server restarts.
- Preserve intentional detachment and normal entity removal.
- Keep the behavior server-authoritative and efficient in multiplayer.

## Status

Early development.
