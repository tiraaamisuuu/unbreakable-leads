Unbreakable Leads 1.1.1 adds the Fabric edition for Minecraft 26.3 and refreshes the separate Paper plugin.

## Choose your jar

| Edition | File | Installation | Requirements |
| --- | --- | --- | --- |
| Fabric | `unbreakable-leads-26.3-1.1.1.jar` | `mods/` | Minecraft 26.3, Java 25, Fabric Loader 0.20.1+, Fabric API 0.165.2+26.3 or a newer 26.3 build |
| Paper | `unbreakable-leads-paper-26.3-1.1.1.jar` | `plugins/` | Paper 26.3, Java 25; built and verified against build 240 |

For single-player, use the Fabric edition. Dedicated servers only need their matching server jar; players do not need to install Unbreakable Leads to join. Install one edition per instance.

Existing configuration files are preserved. Older Minecraft versions require the version-specific jars from earlier releases.

## Changes and validation

- Ports the main Fabric release from Minecraft 26.2 to 26.3.
- Rebuilds the Paper plugin against Paper 26.3 build 240.
- Updates the Gradle wrapper and project metadata and adds automated builds/releases.
- All four configuration tests pass. A dedicated Fabric server loads all six Mixins; both Fabric and Paper reach the ready state and stop cleanly.

Server smoke checks verify loading and startup, not every gameplay scenario. Cross-dimension lead preservation is not supported. See the README for the configuration and manual gameplay checklist.

`SHA256SUMS.txt` contains checksums for both jars.
