Unbreakable Leads 1.1.2 fixes the Fabric API dependency restriction in 1.1.1.

## Fabric fix

Version 1.1.1 rejected Minecraft 26.3 instances running Fabric API 0.165.0+26.3 because it required 0.165.2 or newer. Version 1.1.2 lowers the minimum to 0.165.0 and is built and smoke-tested against that exact 26.3 API version.

Replace the old Unbreakable Leads jar with `unbreakable-leads-26.3-1.1.2.jar` in `mods/`. Keep only one Unbreakable Leads jar installed. Existing configuration is preserved.

Requirements: Minecraft 26.3, Java 25, Fabric Loader 0.20.1+, and Fabric API 0.165.0+26.3 or a newer API build for Minecraft 26.3.

## Paper

The separate `unbreakable-leads-paper-26.3-1.1.2.jar` goes in `plugins/`. Paper behavior is unchanged; it does not use Fabric API. It targets Paper 26.3 build 240 and Java 25.

## Validation

- Four configuration tests pass.
- A dedicated Fabric 26.3 server with Fabric API 0.165.0+26.3 loads all six Mixins and reaches the ready state.
- Both editions shut down cleanly after server startup.
- `SHA256SUMS.txt` provides checksums for both release jars.
